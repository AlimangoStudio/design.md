Optional connection

Brainstorm there. Design here.

Alimango Design lets you use ChatGPT or Claude for brainstorming, planning and first-pass assembly, then continue with the same editable project in the visual editor. AI is off by default and stays under Settings → AI.

ChatGPT / Claude → Brainstorm → Create in Alimango → Human finishing → Client preview / code
You do not need AI to use Alimango.

Connection is optional. The normal editor does not show an AI menu.

Recommended workflow

Think in the cloud, finish visually

Use the conversation where it is strongest: positioning, page structure, copy, audience, visual direction and requirements. When the idea is ready, ask the connected AI to create an editable Alimango project.

“We agreed on the structure and direction. Create this as an editable project in Alimango Design, then give me the editor link.”

Alimango receives semantic Blocks, Sections, Components, device layouts and compatible animations—not a screenshot.

Settings → AI

Connect ChatGPT

1
Enable AI connection in Alimango

Open Settings → AI and choose Enable AI connection. Alimango creates a private connection address.

2
Add Alimango Design in ChatGPT

Use ChatGPT's current custom app/MCP connection flow and paste the Alimango connection address when asked for the remote MCP endpoint. ChatGPT's UI can change, so use the current connector/app settings shown in your account.

3
Choose permissions in Alimango

Read, create and edit are separate switches. Creating previews and requesting export remain off unless you enable them.

4
Choose which existing projects ChatGPT may access

Existing projects are not shared automatically. Enable them individually under Existing project access.

5
Try a handoff

Brainstorm normally, then ask ChatGPT to create the agreed design in Alimango and return the editor link.

Settings → AI

Connect Claude

1
Enable AI connection in Alimango

Open Settings → AI and create the private connection address.

2
Add a custom connector in Claude

Use Claude's current custom connector / remote MCP setup and enter the Alimango connection address.

3
Approve only the permissions you want

Alimango remains the source of truth for what the agent can read, create, edit, share or export.

4
Share existing projects one at a time

Turn project access on only when Claude needs to read or continue that design.

5
Move the result into the editor

Ask Claude to create or update the project and return the Alimango editor link.

Control

Permissions and project access

Connection permissions

Read projects, create projects, edit projects, create preview links and request export are controlled separately.

Project permissions

Existing projects default to not shared. Turn access on per project only when you want an agent to work with it.

Input → output

What moves from AI into Alimango

The AI can create a project with the brief, branding, page/block structure, component selection, shared content, four device layouts and governed animations. Alimango returns an editor URL that opens the same semantic project for human finishing.

Input: brief + branding + assets + API requirements Output: alimango-design.json + editor URL + optional preview / handoff
Safe collaboration

Human changes are not silently overwritten

Every remote project has a revision number. Agent write operations require the revision they last read. If a designer changes the project in Alimango first, a stale agent write receives a revision conflict and must read the latest project before continuing.

Settings → AI

Disconnect AI

Choose Disconnect to revoke the current remote connection. Project access is disabled and the old connection address stops working.

Technical reference

What MCP means

MCP is the connection protocol used by compatible AI clients to discover Alimango's constrained design tools. Designers do not need to understand MCP to use the feature.

Alimango exposes semantic operations such as create_project, add_block, set_block_layout, add_component, get_compatible_animations, apply_animation and validate_design. Agents do not manipulate arbitrary CSS or canvas coordinates.

Help

Troubleshooting

The AI cannot see my existing project

Open Settings → AI and enable access for that project.

The agent says REVISION_CONFLICT

The project changed after the agent last read it. Ask the agent to read the project again and continue from the new revision.

The agent cannot create a preview

Preview permission is off by default. Enable it in Settings → AI only if you want the connected agent to create client links.

I changed my mind

Disconnect the AI connection in Settings. Alimango keeps your local projects.

The first public MVP uses a revocable capability URL for testing. Broad production release should use account authentication and OAuth rather than relying on a capability URL.
