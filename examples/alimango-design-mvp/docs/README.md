# AI connection overview

**Brainstorm there. Design here.**

AI is optional in Alimango Design. It is promoted during onboarding, but it does not live in the main editor menu. Permanent controls are under **Settings → AI**.

The intended workflow is:

`ChatGPT / Claude → brainstorm → create/update semantic project → open in Alimango → human finishing → preview/export`

Existing projects are not shared automatically. Users explicitly enable access per project.
