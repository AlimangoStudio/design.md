# Connect Claude

1. In Alimango, open **Settings → AI**.
2. Select **Enable AI connection**.
3. Copy the generated Alimango connection address.
4. In Claude, use the current custom connector / remote MCP setup and add the Alimango address.
5. Choose Alimango permissions for read, create, edit, preview and export.
6. Explicitly enable access for each existing project Claude should be allowed to continue.
7. Brainstorm in Claude and ask it to create or update the project in Alimango when the direction is ready.
