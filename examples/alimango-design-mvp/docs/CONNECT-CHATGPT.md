# Connect ChatGPT

1. In Alimango, open **Settings → AI**.
2. Select **Enable AI connection**.
3. Copy the generated Alimango connection address.
4. In ChatGPT, use the current custom app / MCP connector setup available to your account and add the Alimango remote MCP address.
5. Return to Alimango and choose the connection permissions you want.
6. Under **Existing project access**, explicitly enable any current project ChatGPT should be allowed to read or edit.
7. Brainstorm in ChatGPT, then ask it to create or update the design in Alimango and return the editor link.

Alimango keeps AI out of the main design menu. Connection and permissions remain under Settings.
