# Brainstorm there, design here

Use ChatGPT or Claude for client discovery, audience, content, information architecture, visual direction and first-pass composition. When the direction is agreed, ask the connected AI to create the design in Alimango.

Suggested handoff prompt:

> We agreed on the structure and direction. Create this as an editable project in Alimango Design, then give me the editor link.

The output is a semantic Alimango project, not a screenshot. The designer can rearrange Desktop, Laptop, Tablet and Mobile independently while shared component identity/content remains intact.
